# Ma-GGom Frontend

국내 마라톤 대회 접수 일정을 큐레이션해 이메일로 알려주는 서비스의 프론트엔드입니다.

## 프로젝트 목적

마라톤 참가자는 대회 접수 일정을 놓치기 쉽습니다.  
Ma-GGom은 흩어진 대회 정보를 수집하고, 사용자가 원하는 조건(지역, 거리, 시간)에 맞춰 접수 정보를 이메일로 전달하는 것을 목표로 합니다.

## 해결하려는 문제

- 대회 공지가 여러 사이트에 분산되어 있음
- 접수 오픈 시점을 수동으로 확인해야 함
- 사용자마다 원하는 지역/코스/알림 시간이 다름

## 서비스 핵심 가치

- 이메일 인증만으로 빠른 진입
- 개인 맞춤형 알림 설정
- 접수 시점 중심의 실질적 알림

## 사용자 흐름 (MVP)

1. 랜딩 페이지에서 이메일 입력 및 인증코드 요청
2. 인증코드 검증 후 사용자 인증 상태 획득
3. 구독 설정 페이지에서 수신 요일/시간, 선호 지역/거리 저장
4. 백엔드 스케줄러가 조건에 맞는 대회를 매칭해 이메일 발송

## 프론트엔드 범위

- 랜딩 페이지 UX 제공
- 이메일 인증(코드 발송/검증) 플로우
- 구독 설정 조회/수정/해지 UI
- 인증 상태 기반 라우트 보호
- 서버 상태/구독자 수 등 랜딩 지표 표시

## 기술 스택

- Next.js App Router + TypeScript + React
- Tailwind CSS
- Zustand (상태 관리)
- JWT(access/refresh) 기반 인증 처리
